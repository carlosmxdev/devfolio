# Mi Portfolio

Portafolio profesional de desarrollador construido con React, Vite, React Router y Tailwind CSS.

## Sobre el porfolio

Este proyecto es un portfolio personal profesional diseñado para mostrar mi perfil, habilidades técnicas, proyectos e información de contacto.

La aplicación usa una arquitectura basada en componentes con componentes reutilizables de React, enrutamiento del lado del cliente, HTML semántico e interfaz responsiva.

## Requerimientos

Antes de ejecutar el proyecto, asegúrate de tener Node.js instalado.

Revisa tus versiones:

```bash
node --version
npm --version
```

## Instalación

Clone the repository:

```bash
git clone https://github.com/carlosmxdev/portfolio.git
```

Enter the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

## Iniciar el servidor

Previsualiza la versión de producción localmente:

```bash
npm run dev
```

Luego abre la URL local que Vite muestra en tu navegador.
